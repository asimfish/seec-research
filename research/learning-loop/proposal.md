## 1. 科学问题与候选主张

我们研究的对象是**经验生产器与学习器共同演化的系统**。每一代学生执行、获取反馈、产生经验；经验进入权重，形成下一代学生；下一代又决定新的经验分布。

需要区分两项输出：

1. 当前能力：在熟悉规则下能否完成任务，以及新规则下首次尝试的表现。
2. 学习能力：权重冻结时，面对新规则，能否用更少交互辨认规则、修正行为、达到同一任务标准。

**候选科学假设**：以任务完成或普通训练进展为反馈的闭环，可能提高当前能力，却没有相应提高新规则下的适应效率；以训练后可迁移的适应收益反馈经验生产器，可能改变这个现象。

这不是已发现的规律，也不假设所有成功驱动的闭环都会退化。如果普通 student-state aggregation、元学习课程或数据量匹配解释全部结果，我们就采用那个解释，不宣称新机制。

我们不能主张首次提出闭环、任务内学习、学习进展奖励、学习历史蒸馏、后训练收益评价或机器人可教性。可能成立的贡献，应是：**证明并定位上述目标错配；给出可计成本的修复机制；在多个公开任务分布中验证跨代的新规则适应收益。** 方法名与复杂系统包装不能替代这三项证据。

## 4. 数学对象：每一代究竟变了什么

任务族为部分可观测过程 `M_τ`。隐藏规则 `τ` 可以是抽屉映射、有效公交关系、Alchemy 的化学变换或协作者的失误规律。学生只接收允许的观测、动作、反馈及 reset 边界；不能输入 τ、规则真值或教师内部推理。

学生 `π_θ(a | o, h)` 在**任务内**保持历史 h，权重 θ 固定。episode reset 不清除同一规则下的学习历史；换规则时必须清除。这与历史 Planar 的每决策窗口零状态协议是不同实验，不能混用。

令 `R_θ(τ,b)` 为先用 b 个登记交互预算探索/尝试后，在该任务上的评测表现。离散预算 `B={0,1,3,5,10}`；每次尝试与评测动作均计成本。`b=0` 必须是未接收该规则经验的首次尝试，不是“先探索 20 步”的旧 Cooking 第一执行段。

总表现与适应部分分别定义为：

```
Q_total(θ; P) = E[sum_b w_b R_θ(τ,b)]
Q_adapt(θ; P) = E[sum_{b>0} w_b (R_θ(τ,b) - R_θ(τ,0))]
```

同时报告达到固定表现标准所需的预算（未达到记右删失）、累计 regret、R(0)、最终表现及任务级完整曲线。不能只报斜率或归一化 headroom：差的首次表现会人为放大可提升空间。

外层的学习算子与经验生产器为：

```
D_g ~ G_{φ_g}(π_{θ_g}, training_worlds)
θ_{g+1} = U(θ_g, D_g; fixed learner configuration, fixed update budget)
φ_{g+1} = UpdateProducer(φ_g, evidence about D_g's downstream utility)
```

科学对象是 `(θ_g, φ_g, D_g)` 的代际动力学。不是简单把更多日志塞进模型，也不是把一个任务内的 reward 提升叫作递归自我改进。

## 5. 最小可执行机制：用实际吸收后的适应收益给经验生产器信用

先保持学习器、输入、teacher 标签接口和优化器不变。学习器采用因果序列模型，动作监督使用完整实际历史；事实辅助头不作为核心，因为已有覆盖实验没有支持它在 student-state 条件下持续带来增益。

经验生产器最初采用一个有限配方选择器，而非直接让大模型自由改程序。配方只能选择已登记的训练任务配置、目标、交互预算与采集条件；**主对比中所有配方使用同一种学生采集策略和可见历史 teacher**。不要同时改变教师强度、模型或学生接管率来冒充信用目标的效果。

每一轮：

1. 从当前学生的真实执行采集多个候选经验批次。保存整段 `动作→后果→反馈→后续行为`，包括失败与恢复。没有奖励的动作也可以提供信息。不能用教师前缀替换学生原本访问的状态。
2. 将同一个 θ 与优化器状态复制到候选分支；每个分支进行相同 κ 次更新。候选经验之间有互补性，**按批次计信用**，不先假设每个 transition 的价值可相加。
3. 在源任务之外的**课程反馈任务池**上评测每个分支。每次任务内权重冻结，从空历史开始；反馈任务与源任务的具体规则/实例不重叠，但属于训练侧。反馈池影响生产器，不能叫 held-out test。
4. 信用为分支相对未更新学生的 `ΔQ_adapt`。同时要求 `ΔQ_total` 与首次表现不越过预登记的损害界，防止通过降低首次表现“创造学习空间”。初版选择器可直接做有限候选选择；评分预测器/agent 自主设计随后再引入。
5. 按信用选择或重加权经验，在相同正式预算下吸收；用新的学生产生下一轮经验。短分支不是新一代正式结果，不能挑其中最好 checkpoint 写进主结果。
6. 每代进行独立封存评测。测试规则不反馈给生产器；版本与阈值不能根据封存结果修订。

这是一个有成本的反事实近似：不同经验从同一起点经过相同训练后，比较学习能力变化。它与 SOAR 的训练后收益评价、通用 TSCL 的目标增量以及 Meta-Teaching 有直接重合。我们必须证明具体目标与数据闭环的作用，而不是宣称外层训练本身新颖。

**预算守恒**：候选采集、失败重试、全部标签、被拒绝批次、短训练分支、反馈评测、正式训练、reset 全部入账。主实验按总交互预算和总优化器更新预算分别给性能曲线，不能只对齐最终正式更新步数。若把选择开销纳入后优势消失，结论是机制有选择价值但目前没有成本收益。

**反馈过拟合**：反馈任务池定期换规则；记录重复访问；用新生成的训练侧审计任务测短分支预测长期收益的能力。完整封存测试不参与评分器训练、配方选择或 go/no-go。

**适用范围**：闭环首先在可重放的模拟/符号环境中验证。真实机器人上不直接分叉物理现场；可在已校准仿真中做评分，真机只执行选定批次并验证迁移。仿真评分能否预测真机的学习收益是另一个需要实验的问题。

官方入口：[DREAM](https://github.com/ezliu/dream)、[Alchemy](https://github.com/google-deepmind/dm_alchemy)、[MEWA](https://github.com/RStoican/MEWA)。本轮只读 checkout：Alchemy `68a26254b5c0f15e84fa0c15d66bf0c626ede8e0`，MEWA `3dcda1d7623d3bf32dccb5bf1e0fccb6eaae3ced`。有仓库不等于运行可复现；Alchemy 已归档，安装兼容性必须另外验证。

这里主要的数据集是**在线生成并冻结的交互数据集**：每条含观测、动作、反馈、任务边界、episode 边界、采集策略身份、允许标签及账本成本。静态成功示范用于技能先验或吸收对照，不是闭环因果证据。

基准中的原始规则集、任务奖励与测试分布先固定。生产器只能改变训练任务的选择及经验预算，不能修改测试环境/阈值以使门通过。Alchemy 先保留官方配置，再做明确登记的 chemistry 身份或 graph 结构切分；不能凭我们筛选过的容易子集声称完整 Alchemy 成绩。

## 7. 必须比较谁：两层比较，避免弱基线

### 7.1 同一学习器上的机制比较

所有臂共用初始权重、模型、实际学生采集策略、动作标签接口、完整因果历史与测试任务；只改变配方选择/信用。

| 臂 | 生产器的反馈 | 要排除的解释 |
|---|---|---|
| Uniform + student aggregation | 均匀配方 | 普通 DAgger 式分布覆盖已足够 |
| Task success | 采集任务的完成率/成功经验选择；仍保留被选 episode 的失败前缀 | 普通成功驱动的 data flywheel 已足够 |
| Information/uncertainty | 对任务相关隐藏变量的信息或不确定性代理 | 任何主动探索/信息增益都会有相同效果 |
| Learning progress | 学生在课程任务上的表现进展，如 TSCL/ALP-GMM 型选择 | 普通课程进展而非适应目标解释效果 |
| SOAR-style credit | 同起点短训练后，在反馈任务上首次/单次表现的增量 | 只要实际评价训练收益就够，不需评价适应 |
| Meta-teaching objective | 同一候选与成本，使用登记的适应后元目标/损失 | 已有元课程与我们的信用无实质差别 |
| Proposed adaptation credit | `ΔQ_adapt`，伴随整体表现及 R(0) 保持条件 | 核心候选；若不优于最接近两臂，不能声称新机制 |

TSCL 型、SOAR-style 和 meta-teaching-objective 在新域的受控实现，不冒称原论文数值的原样复现。PLR 是 TD-critic 的方法，不能把监督 CE 优先采样随意命名成完整 PLR。

### 7.2 完整方法与外部效率比较

至少在公开元学习域补齐 AD、DPT、DREAM、VariBAD/RL² 的正式实现或明确披露的协议适配；再加入 CARML 或适用的元课程方法。先核对原始协议与较小运行，再与我们的统一任务预算做补充对比。统一 GRU 的自写动作 BC 不是 AD/DPT/DREAM 的完整替代。

更强 teacher、特权训练任务 ID、模型规模、优化器更新与预训练成本分别记录。原方法正常使用的训练特权不应被偷偷禁掉来制造优势；同时报告共同信息边界的受控比较。

Agent 系统阶段再比较固定 agent、只更新检索记忆、只做普通 OPD、共同演化经验生产器与权重。先证实信用机制，再增加大模型 agent；不能把其额外推理预算算作免费。

## 8. 实验—结论对应关系

| 编号 | 实验与主要比较 | 支持结论的必要观察 | 若没有出现，应怎样解释 |
|---|---|---|---|
| E0 | No-memory、random、不适应多任务策略、oracle/ideal observer；原始域与新规则切分 | 学习预算产生可辨识增益，oracle 与弱策略存在空间，非全部地板/天花板 | 基准无法辨认该问题，或学习器未就绪；不能马上解释为新方法失败/成功 |
| E1 | 固定同一学生、同一候选批次，比较成功分数、进展信用、短训练适应信用对**较长吸收后收益**的排序 | 适应信用能在新的训练侧审计任务上更准确预测实际适应收益；至少与 source progress 的选择不同 | 信用代理没有独立价值；不扩大系统，也不根据封存测试换代理 |
| E2 | `g=0,1,2,3` 三次经验—权重循环；生产器目标受控；新规则多预算曲线 | 普通目标与适应目标在学习效率上分离，候选的优势跨代持续且不靠较差的 R(0) 创造 headroom | 只有一次数据增益，不是持续的下一代更会学习；若 DAgger 追平，采用覆盖解释 |
| E3 | 固定采集大池、相同数据量与吸收预算，反事实经验选择；交换生成器/经验批次；普通重放与学习进展对照 | 从哪个生产器来的数据，而非模型、额外更新或 teacher 变化，能因果改变适应 | 可能是计算/标签强度/容量优势，不是经验生产机制 |
| E4 | 历史清空、历史/反馈顺序打乱、无关扰动变化；保持完整观察而只改损失；task-aware oracle | 在新规则上保留正确反馈有增益，破坏规则证据而保持表面任务信息会削弱增益；对无关信息稳定 | 可能是在识别已知任务或记忆目标，而非用交互辨认新规则 |
| E5 | 源分布到未见有效公交规则、Alchemy chemistry/graph、MEWA worker 分布；分别报告普通实例与结构迁移 | 在第二个性质不同的域上重复方向；不把位置、噪声 seed 与新规则混为一谈 | 单域课程效果，不能推广为通用 learning-to-learn engine |
| E6 | 总交互/标签/短训练/反馈预算匹配，加入“不选而把同额成本多训练/多采数据”的强控制 | 将选择成本计入后仍有适应效率/总成本优势，或明确给出收益—成本折衷 | 有信用评价效果但无预算优势；如实报告，不删掉失败分支成本 |
| E7 | 机器人任务，固定运动原语与校准 build；未知机制/反馈，模拟评分与真实验证 | 物理重放/恢复门通过，真正新机制上有限交互后改善，模拟信用预测真实收益 | 仅模拟或符号结果；未过物理门不能声称真实机器人 RSI |

统计单位是独立训练 seed/独立完整闭环运行；大量 episode 不替代 seed。主对比、固定预算、任务分布与家族在确认实验前冻结。先做 3 个新的开发 seed；主实验 seed 数用独立开发数据的配对方差与最小有意义差异决定，不把开发数据合并为确认结果。

主图应同时呈现：①代际已有能力；②每代新规则适应曲线；③总成本—适应效率曲线。只画最终成功率无法回答本论文的问题。结构迁移/噪声面板与失败机制案例放后续图；方法图突出生产器收到的是**经验被吸收之后的学习收益**。

## 9. 已有初步结果能说明什么

以下是既有 `student_coverage_v1/run1` 的开发试验，不是本方案的新闭环实验。3 个 seed；12 个 continuation run；每臂两轮追加共 600 次更新，累计 7,200 次更新；所有 seed/失败预测均保留。

| 经验采集与损失 | 平均成功率 | 3 个 seed 的成功率 |
|---|---:|---|
| 固定离线历史 + 动作监督 | 30.03% | 27.20 / 33.60 / 29.28 |
| 固定离线历史 + 事实辅助 | 60.53% | 59.36 / 65.60 / 56.64 |
| 学生实际历史 + 动作监督 | **81.33%** | 66.72 / 94.56 / 82.72 |
| 学生实际历史 + 事实辅助 | 78.51% | 81.92 / 82.56 / 71.04 |

动作监督从离线到学生历史增加 51.31 个百分点；事实辅助在学生历史条件下平均减少 2.83 个百分点，seed 方向不一致。原登记的“事实辅助增益在覆盖后仍存在”未通过。重放与输入/动作核对通过，但只是 action/reset replay，不是物理 snapshot E4。

更新步数及训练序列计数对齐，但学生采集动作量约 101k，离线约 85k，交互/标签成本没有完全对齐；首次执行已受 20 步探索影响；旧有限任务族与 seed 被重复使用。不能把这些数字称为完整 AD/DREAM 基线复现或确认性显著结果。

**可用结论**：现有实现里 student-state coverage 是必须保留的强解释，新的经验生成机制至少要击败它。**不能推出**：学习能力递归退化、下一代学习加速、事实头原创新颖、跨任务普适或真实机器人有效。

## 10. 下一次最有信息量的试验与成本上限

在实现新 agent engine 前，先做 E1 的短信用有效性诊断：

- 3 个新开发 seed；每个 seed 同一学生起点；8 个登记候选经验批次。
- 每批 64 次短更新评分、300 次较长更新独立检验；从同一起点分别分叉，不累计混合。合计最多 `3×8×(64+300)=8,736` 次更新。
- 同一批候选同时计算 success、source progress、适应信用；不能给候选方法独占更多可选数据。反馈池与检验池都是训练侧，彼此规则/实例分开。
- 原始预算覆盖 b=0；先从 `0/1/3/5` 尝试开始，horizon 与公开域固定。每个任务的评分动作与检验动作全部计成本；具体任务数与动作上限需要根据 E0 运行时间落成下一份预注册。
- 同时保留四个解释：H1 普通覆盖已解释；H2 元课程/训练收益可解释；H3 适应信用有额外可迁移价值；H4 额外成本/首次表现改变制造表面收益。

预注册时给出候选批次身份、初始 θ/优化器、任务切分、评分统计量、不得超过的交互和时间上限。当前这一节是可执行草案，**没有伪装成已经冻结或已经运行**。

若短信用不预测较长吸收后的收益，或者 meta-teaching 目标完全追平，不推进大规模闭环并不否定该方向的重要性；它说明当前方法定位或信用近似不成立。若 E1 有分离，再运行 E2 的 4 代受控闭环，随后才是跨域与机器人扩展。
