# 从“完成任务”转向“学习如何学会任务”：研究更新

更新：2026-10-13。本文件是候选方法与初步机制诊断，不是完成的 ICML 方法论文。历史 SEEC 的停止结论保留；这是一份新的研究协议。

## 先回答新颖性

**四个观点都不是我们首次提出的。** 它们构成值得研究的背景，但不能直接列为贡献。尤其不能把“Robot RSI + OPD”组合名称当作新方法。

| 我们讨论的观点 | 最直接的先例 | 对创新性的影响 |
|---|---|---|
| 完成任务的知识与获得知识的能力不同 | [RL²](https://arxiv.org/abs/1611.02779)、[DREAM / ICML 2021](https://proceedings.mlr.press/v139/liu21s.html)、[LMPC](https://robot-teaching.github.io/) | 不是新问题。LMPC 已经在机器人上微调教学历史，以改善新任务的可教性。 |
| 利用交互辨认未知规则 | [DREAM](https://proceedings.mlr.press/v139/liu21s.html)、[Algorithm Distillation](https://arxiv.org/abs/2210.14215) | 任务相关探索与从跨 episode 历史学习适应程序已有直接方法。 |
| 当前完成价值不等于后续学习价值 | [内在动机的计算分类](https://www.frontiersin.org/journals/neurorobotics/articles/10.3389/neuro.12.006.2007/full)、DREAM | 长期收益、信息获取和学习进展早已被区分。不能仅更换价值函数的名称。 |
| 任务内学习程序与慢速经验吸收 | RL²、AD、LMPC、[RoboTTT](https://research.nvidia.com/labs/gear/robottt/) | 快慢学习、学习历史蒸馏、长上下文吸收已有先例。 |
| 学生状态上的专家标注与蒸馏 | [DAgger](https://proceedings.mlr.press/v15/ross11a.html)、[RE-0](https://arxiv.org/html/2609.32416v1) | on-policy 标签本身不新。RE-0 更直接覆盖局部反事实验证、收益准入与蒸馏。 |
| 验证经验、外部记忆与自我改进闭环 | [RoboHarn-Evo](https://arxiv.org/html/2609.37583v1)、[Flux-OPD](https://arxiv.org/html/2607.28022v1) | 验证 + 双回路、上下文指导进入参数已经有人研究；不能把系统框图当新颖性证明。 |

本轮复用上一轮已核验的 16 篇标识，新增核验 DREAM 与 2007 年内在动机论文；学习实验阶段又补查 UNREAL、VariBAD 和 Humplik 的 task inference，共 21 篇。阅读深度、官方链接和局限逐篇保留在 reading_notes.json；预印本不标成已录用论文。这个集合足以否定上述宽泛的“首次”，**不足以证明一个更窄的新机制无人做过**。公开标识可核验不等于其性能结果被我们复现。

## 值得继续检验的具体缺口

候选问题是：**机器人能否从自己实际执行产生的、可能不完整或含糊的反馈中，学会更准确地更新任务假设，并将这种更新方式迁移到下一项未知任务？**

这里有两类不同错误：某动作没有执行，不能据此认定任务规则不允许它；动作确实执行但没有目标效果，也不能仅靠终局失败确定原因。我们研究的对象应包括“是否值得改变任务假设”，而不只是下一动作。独立执行证据必须与策略共享学生可见边界，不能通过额外隐藏标签制造优势。

这一缺口是候选，不是已确认的新贡献。它也可能被合理的 Bayes/POMDP 更新、DREAM 的信息目标或 AD 的完整历史充分解释；强对照正是用来淘汰这种情况的。

## 数学对象与可实现机制

任务 \(\tau\sim p(\tau)\) 包含未知的工具映射或先决条件；熟练控制原语保持不变。第 \(k\) 次尝试得到实际历史 \(H_k\)。快回路只更新任务内状态 \(m_k\)，在新任务开始时清空；慢回路更新参数 \(\theta\)，并在未见过的 \(\tau\) 上评测。

\[
m_{k+1}=U_\theta(m_k,e_k),\qquad
\pi_\theta(a\mid o,m_k),\qquad
A_K(\theta)=\mathbb E_\tau\left[\frac1K\sum_{k=1}^K Y_{\tau,k}\right].
\]

经验 \(e\) 至少保存观测、动作提议、实际执行、后果和评价的来源；未知执行状态保留 unknown。可选的执行判定 \(q_v(z\mid e)\) 不能访问隐藏任务规则。结构化信念参考模型使用

\[
b_{k+1}(\tau)\propto b_k(\tau)\sum_z q_v(z\mid e_k)\,p(e_k\mid\tau,z).
\]

它是强基线，不是我们的发明。若策略只是复现这种过滤规则，贡献只能是实现与适用边界。

在合法、同分布的任务重置上比较“提供 / 屏蔽某条已观察经验”，定义后续学习信用

\[
g_{\rm learn}(e,H)=\mathbb E\left[\sum_{j=k+1}^{K}Y_j\mid\mathrm{do}(H\cup e)\right]
-\mathbb E\left[\sum_{j=k+1}^{K}Y_j\mid\mathrm{do}(H)\right].
\]

也报告动作成本版本；不能在成功率已经饱和时声称有成功率收益。控制当前物理状态、可用工具、预算、记忆长度与随机数；不把任意模拟器快照当成可恢复状态。这个量是训练信用的候选估计，不是已证明的因果定理。测量未来后果所需的 rollout 逐项计费。

拟实现的经验吸收有两个明确目标：

1. 在**学生实际访问的历史**上预测下一安全动作，模仿目标只能绑定实际可见输入。
2. 预测历史更新 / 下一次应测试的假设，把没有立即完成任务、但改善后续适应的经验保留下来。失败轨迹作为上下文，不无条件作为正例动作。

训练形式可用 \(\mathcal L=\mathcal L_{\rm action}+\lambda\mathcal L_{\rm update}\)，并比较统一权重、终局权重、信息增益权重和估计的学习信用权重。所有这些都是待检验实现选择，不因公式更复杂而自动新颖。未来结果标签只进入训练目标，不进入当前策略输入。OPD 标签和证据由在线学生历史生成；测试时撤去教师、证书与隐藏任务变量。

## 已执行：公开 Cooking 环境上的初步结果

使用 [DREAM 官方代码](https://github.com/ezliu/dream)，固定 revision `d52204c94067641df6e6649b19abb359b87ff028`。原版状态转移、观测、奖励和 20 步 horizon 不变。环境是 3×3 食材抽屉网格，不是接触仿真或真机。原论文默认 63 个训练映射、1 个测试映射；我们明确改为独立登记的 32 / 8 / 24 映射切分，以做诊断，**不是论文成绩复现**。

24 个未知映射产生 125 个有效目标实例。每个实例先有 20 步探索，然后连续执行同一目标 5 次；5 个 seed 只改变搜索并列顺序，不是神经训练种子。六臂各有 3,125 次任务执行，合计 18,750 次执行和 3,750 次探索；独立泛化条件只有 24 个映射，不能把这些重复 episode 当成 18,750 个独立样本。

| 对照 | 终局成功 | 平均执行步数 | 第一次 → 第五次 |
|---|---:|---:|---:|
| 每次清空任务历史 | 3125 / 3125 | 12.8896 | 12.8896 → 12.8896 |
| 只从终局成功 episode 保留历史 | 3125 / 3125 | 10.82112 | 12.8896 → 10.3040 |
| 完整有效历史的符号策略 | 3125 / 3125 | 10.3040 | 10.3040 → 10.3040 |
| 结构化充分事实记忆 | 3125 / 3125 | 10.3040 | 10.3040 → 10.3040 |
| 同 20 步预算随机探索 + 历史 | 3125 / 3125 | 10.69568 | 11.9552 → 10.3808 |
| 特权映射 oracle（诊断上界） | 3125 / 3125 | 10.3040 | 10.3040 → 10.3040 |

充分事实记忆与完整有效历史**逐条相同**，两者在这个有限环境里实现的是同一参考策略；不能当成新方法胜出。探索没有当场完成指定目标，却降低后续执行步数约 20.06%；两臂均额外支付 20 步探索，算入 5 次任务的总预算后节省约 15.31%。所有成功率均到天花板，成功率上的 \(g_{\rm learn}\) 在本轮为零，没有成功率优势，也没有“越来越会学习”的参数证据。

第一轮方向适配写错，连 oracle 也失败；已明确标 INVALID 并保留，修复仅调整 up/down 的编号，未改环境或实验参数。第二轮是本表唯一有效结果。方向契约、全部 64 映射的 oracle、未知 pickup 拒绝写入知识等测试已通过。所有记录另做独立 reset-and-action replay；这不是旧 Lift snapshot E4 的替代品。

## 新增：三种子的真实学习实验

已完成 9 次循环行为克隆训练，三个优化器种子为 7、19、41。使用相同的 32 个训练映射、统一源历史、初始权重、minibatch 抽样顺序、GRU 结构和每臂 800 次更新。测试覆盖 24 个映射的 125 个有效目标，每个 checkpoint 自主执行探索和五次尝试。没有教师前缀，辅助标签和符号记忆不进入策略。

| 学习臂 | 五次尝试平均成功率 | 三个种子的成功率 | 清空任务内记忆后 |
|---|---:|---|---:|
| 完整历史，动作监督 | 24.21% | 27.84 / 24.80 / 20.00% | 18.67% |
| 动作 + 当前状态辅助 | 34.29% | 34.56 / 36.48 / 31.84% | 18.13% |
| 动作 + 已观察事实辅助 | 56.80% | 57.92 / 60.80 / 51.68% | 24.00% |
| 符号完整历史参考 | 100.00% | 三个搜索顺序均成功 | 不适用 |

实际训练目标为动作交叉熵加 0.2 倍辅助交叉熵。事实标签只从当前时刻之前实际 pickup 的库存观测重建，未知抽屉标 unknown；当前状态对照预测当前库存和碗里的前两个槽。三个模型都有相同的输出头，只有辅助目标不同。输入含真实终局反馈，循环状态在同一任务的尝试间保留、新任务清空。

本轮事实辅助比动作监督高 32.59 个百分点，比当前状态辅助高 22.51 个百分点，三个种子的方向一致；清空其记忆下降 32.80 个百分点，满足登记的 pilot 预测。这是小规模、探索性学习证据，**不是新算法优越性、OPD、RSI 或机器人效果**。符号参考仍为 100%，说明学习器还有很大差距；三个 optimizer seed 不能当成几千个独立训练样本。

事实辅助的第 1 次到第 5 次成功率为 54.93% → 57.60%，只增加 2.67 个百分点；第 1 次之前已经进行了 20 步交互探索，不能称为零样本。三个模型的探索前缀实际上相同。因此本轮最强的结论是改善对已有信息的利用，而不是学会更好的主动试验、持续自我改进或更快的参数吸收。

主实验日志 19,098 条完整覆盖，322,100 个评测动作逐步重放，295,280 次神经策略决策从 checkpoint 重算一致。第一轮因未将终局反馈送入模型而中止并标 INVALID，保留原计划和代码；纠正后未改任务、期限、切分、种子或预算。失效运行的额外计算成本也单独保留。

### 机制排查：相同历史与反馈遮蔽

主实验结果后，另登记了不再训练的机制检查：九个冻结 checkpoint 接收同一份真实的 20 步探索历史，再将其中食材库存反馈遮蔽；执行期仍读原始观测。这个检查使用外部提供的共同前缀，**不并入自主探索的主结果**，遮蔽也不冒充模拟器真实输出。

独立核验发现，九个模型在 125 个任务上的 1,125 段自主探索前缀，全部与共同前缀逐步相同；所以主结果的差异在这组任务上并非来自探索采到不同信息。遮蔽后 125 段模型前缀输入只有一种，食材映射证据被移除。

| 冻结模型 | 共同真实前缀 | 遮蔽食材反馈 | 真实 − 遮蔽 |
|---|---:|---:|---:|
| 动作监督 | 24.21% | 26.99% | −2.77 个百分点 |
| 当前状态辅助 | 34.29% | 32.91% | +1.39 个百分点 |
| 已观察事实辅助 | 56.80% | 29.81% | +26.99 个百分点 |

11,250 条记录、185,786 次策略决策独立重算，观测与奖励重放最大差为 0，九个 checkpoint 字节未变。这个检查支持事实辅助模型在使用历史反馈，而非仅增加输出头或获得更好的探索前缀；动作基线遮蔽后反而改善，也必须报告。干预会改变输入分布，且是在主结果后登记，不能把上下文删除直接解释为新的因果学习信用或独立确认性证据。

### 更直接的先例限制

新查到的 [Humplik 等，2019](https://arxiv.org/pdf/1905.06424) 已研究任务信念监督，并明确比较 auxiliary-head agent（图 1C）。[VariBAD](https://arxiv.org/abs/1910.08348) 学习任务推断与不确定性条件决策；[UNREAL](https://arxiv.org/abs/1611.05397) 已展示辅助目标改善共享表示。因此，“加一个事实预测头”不是新贡献，本轮只是给出了一个可复现的诊断：完整历史输入与动作损失，并不保证学得利用历史的能力。

更窄的候选仍是**在学生访问的历史中，判断哪些实际后果支持更新任务假设，并把经验证的更新经验吸收进策略**。需要与监督信念、VariBAD / DREAM、AD、同信息的结构化信念参考，以及学生状态采集对照进一步比较。当前 Cooking 的执行完全确定，尚未检验“未执行 vs 规则不允许”、未来学习信用或新先决条件。

## 下一步基准与对照

| 层次 | 基准 / 问题 | 必要比较 | 能证明什么 |
|---|---|---|---|
| 已完成机制诊断 | DREAM Cooking，未知食材映射 | 无跨试次历史、终局筛选、完整有效历史、随机探索、oracle | 信息保留与探索成本；目前不能分离新方法收益 |
| 下一项学习实验 | DREAM Cooking / Distracting Bus，严格新映射，任务相关与无关信息共存 | 从头训练的 DREAM / RL²；AD 风格完整学习历史；同预算 action-only / update-only / 两者；反馈感知信念参考 | 学得程序是否改善新任务的适应曲线，是否超过强历史基线 |
| 任务依赖验证 | [MEWA 官方论文](https://research.manchester.ac.uk/en/publications/mewa-a-benchmark-for-meta-learning-in-collaborative-working-agent/)，具体版本与可运行协议待冻结 | 完整历史、结构化信念、同预算探索、去验证/去信用/去 OPD | 新先决条件的学习；不能只换位置和纹理 |
| 机器人落地 | 已有 SafeLab / RoboCore 控制技能上新增隐藏按钮或锁扣依赖；公开与扩展设置分开 | 固定 VLM、完整历史、LMPC 式历史吸收、学生状态标注、Bayes 参考 | 执行失效与规则变化是否被区分，教师撤除后的新规则学习 |

Meta-World 可作为连续控制层验证，但其任务标签或目标变化不能直接充当未知规则学习的证据。DREAM 原作者训练方法、RL²、AD、LMPC、VariBAD、MEWA、VLA 和机器人新规则实验本轮均 **NOT_RUN**；不把手工规则策略改名成这些算法。

下一项预测检查优先选 **零奖励但任务相关的证据 vs 高信息量但任务无关的证据**，再独立加入“未执行 / 已执行无效果”的可见回执。每个变更单独登记；执行失效比例不能看到成绩后调。候选信用机制必须超过同信息、同成本的完整历史和反馈感知信念参考；若不能，缩小主张或停止该机制，不能继续靠删弱基线制造优势。

## 研究状态

2026-10-13 另按用户要求恢复了七段机器人场景 / 子操作历史，并重新检查 NAS 资产。已有 layout v4 的 A/B/C 实验室、四瓶完整 demo 与 20 路视频，没有被本方向废弃；新版 [场景网页](https://asimfish.github.io/seec-research/scenes.html) 与学习页分别展示。checkpoint 容器与恢复 adapter 有实现，但历史局部携行 PASS 使用运动学支撑，全场景恢复门仍 FAIL；任意运动中断点、新进程多阶段链与完整随机 / 任务图继承未闭合。新审计不得升级为学习效果，Cooking 成功率也不证明这些能力。[本次方案判断](https://asimfish.github.io/seec-research/research/scene-recovery-report.md) 明确列出实现与缺口。

- 背景观点新颖性：否定宽泛首次；窄机制新颖性仍未确认。
- 初步标准环境诊断：符号参考到天花板；学习器 24.21 / 34.29 / 56.80%，事实辅助有探索性收益，仍低于符号参考。
- 学习程序：三种子的循环 BC 与事实辅助诊断完成；on-policy 参数吸收、学习信用和机器人新规则尚未运行。
- 历史 Lift / Planar 停止结论：保持，不复用为本方向的效果。
- ICML readiness、机器人效果、预算优势、递归加速：不作主张。

现阶段更准确的故事是：**先证明我们是否能学到一个优于完整历史和任务相关探索基线的“任务学习程序”，再谈它能否被长期吸收。**
