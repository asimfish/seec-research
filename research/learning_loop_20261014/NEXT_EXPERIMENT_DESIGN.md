# 信用试验失败后的下一项设计

2026-10-14；**设计草案，不是新的预登记或实验结果**。
证据来源：`credit_pilot_v1/run1/analysis.json`、`metric_diagnostic.json`、
`verification.json`。旧协议与判定不变，不在旧面板上调出一个“通过”。

## 1. 这轮究竟排除了什么

短训练后的适应增量能预测较长训练后的同一代理，却不保证经验值得吸收。
选中经验的平均首次成功下降 13.19 个百分点，后续仅增加 1.16 个百分点。
因此，`后续成功 − 首次成功` 同时依赖学习与首次能力，不能独立识别“更会学习”。
短反馈的保持守卫也没有迁移到短审计规则；不把它归结为训练变长。

这不是闭环假设整体被否证，也不是新规律的充分证据。当前得到的是一个
可复现的测量与选择失败。下一项必须检验：经验吸收能否在保持先验能力的
同时，提高利用交互解决新规则的效率。

## 2. 使用变化的实例，保持潜在规则

下一域采用官方 **Symbolic Alchemy**；源 revision：
`68a26254b5c0f15e84fa0c15d66bf0c626ede8e0`。
先使用原版公开任务，不修改奖励、转移或物体生成以提高某个臂的通过率。
同一 episode 内化学规律保持，新的 trial 产生新 stones / potions，避免仅重复
同一目标带来的路径记忆。正式 level、实例数、动作期限和切分将在 E0 完成后
单独登记；当前没有 Alchemy 训练结果。

E0 只做基准资格检查：

1. 原环境安装、观测 / 动作规格、确定性记录重放；软件冒烟与科学结果分开。
2. 逐项确认策略只读可见观测、自己动作、奖励与 trial 标记。隐藏化学状态只
   进入环境或分析，不进入学生，也不由封装器提供推断标签。
3. 比较无跨 trial 记忆的策略、保留交互的官方理想观察者和特权 oracle。
   官方 bot 若读取非可见内部字段，先标为特权参考，不能直接称可执行学生基线。
4. 检验原域的学习空间：跨 trial 信息是否帮助新物体；动作与 reset 总成本
   是否可计算。若全在地板或天花板，报告 E0 不适合当前估计量，而非调效果。

## 3. 目标必须是固定标准与实际预算

令隐藏规律为 `τ`，trial 实例为 `x_j`，交互历史为 `H`。评测时权重 `θ` 固定：

`a_t ~ π_θ(a | o_t, H_t)`。

主输出应包含：固定累计动作预算下的新实例回报曲线 `J_θ(b)`、累计回报或
与登记参考的累计 regret、达到**共同固定标准**的动作成本 `T_θ(q)`，以及首次
与已掌握规则的能力保持。`q` 不能相对于每个模型自己的较低起点定义。
未达到标准的运行记为失败 / 右删失并报告，不能仅对成功者计算“省步数”。

候选信用可研究同预算的绝对效用差：

`C(D; θ) = Σ_b w_b [J_{U(θ,D)}(b) − J_θ(b)]`，

同时要求保留独立规则子族上的能力。生产器只用训练侧反馈；主测试不能参与
候选选择、守卫、早停或阈值修改。保持守卫是否能跨规则迁移也是独立结果。
短训练分支仍从相同参数与优化器状态出发；被拒候选的成本全部计入。

这个式子本身接近 SOAR / cooperative TSCL / Meta-Teaching，**不作为首创**。
需要证明的增量是：哪些经验通过何种可解释机制，改变了新规则交互的价值，
且不能由当前先验更强、普通覆盖、课程或额外标签解释。

## 4. 不能缺的对照与解释检验

| 比较 | 保持什么一致 | 能回答的问题 |
|---|---|---|
| uniform / task-success / total-return credit / adaptation-cost credit | 学生、候选库、短更新、标签接口 | 不同生产反馈是否真的选出更有用的经验 |
| 学生历史聚合 / 普通元课程 | 自主交互与整体成本 | 收益是否仅由访问状态覆盖或课程解释 |
| 有效交互上下文 / 清空跨 trial 记忆 | checkpoint、原版实例分布 | 新实例收益是否需要过去的交互 |
| 共同历史的反馈干预 | 历史长度与成本；另报告分布改变 | 模型是否利用规则证据；不是单独的因果证明 |
| 相同先验、不同获得信息的行为 | 可见信息与初始能力 | 提升来自先验完成能力还是主动辨认规律 |
| 短保持池 / 新规则子族保持池 | 标准、预算、冻结参数 | 选择守卫能否迁移，是否再次奖励能力损害 |

“相同先验”的对照必须是实测匹配或共同 checkpoint 分叉，不能只按模型名声称。
官方 DREAM / AD / DPT / 元课程复现与自写 GRU 行为克隆是不同层次的对照，分别列出。
若普通总回报信用或元课程追平，就采用更简单解释。

## 5. 扩大闭环之前的顺序

E0 基准与边界 → 新计划、源码与预算登记 → 同源候选的短 / 长信用验证 →
跨规则能力保持 → 才考虑多代经验生产。每代分别报告首次能力、实际交互成本、
新实例回报和训练成本。不能以多个训练阶段串联、评分更大或论文框架更复杂
来代替闭环持续改善学习能力的证据。

创新性仍待验证。CARML、SOAR、Meta-Teaching、LMPC 与反馈学习是必须正面比较
的近邻；不能用特点表里未阅读完整方法的空格支撑“没人做过”。机器人实验证据
另行建立，现有 Lift / Planar 停止与场景渲染审计不承担该结论。
